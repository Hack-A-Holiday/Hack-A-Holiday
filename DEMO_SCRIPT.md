## 📋 Demo Checklist

### Before Demo:
- [ ] Ensure both frontend (localhost:3000) and backend (localhost:4000) are running
- [ ] Clear browser cache and cookies
- [ ] Have Google account ready for sign-in
- [ ] Test all major features work
- [ ] Prepare backup screenshots if APIs are slow

### Key Features to Highlight:
- [ ] Google OAuth authentication
- [ ] AI-powered natural language processing
- [ ] Real-time flight data from Kiwi.com
- [ ] Hotel search with Booking.com
- [ ] TripAdvisor attractions integration
- [ ] Interactive 3D globe
- [ ] Dark mode support
- [ ] Responsive design
- [ ] Trip history and analytics
- [ ] Personalized recommendations

### Technical Stack to Mention:
- **Frontend**: Next.js, React, TypeScript
- **Backend**: Node.js, Express
- **AI**: AWS Bedrock Nova Pro & Nova Lite
- **Database**: DynamoDB
- **APIs**: Kiwi.com, Booking.com, TripAdvisor
- **Authentication**: Firebase Auth + Google OAuth
- **Deployment**: Vercel + Render

### Backup Talking Points:
- Real-time API integrations with fallback strategies
- Intelligent currency detection and formatting
- Context-aware AI conversations
- Secure user data management
- Scalable cloud architecture
- Mobile-responsive design
